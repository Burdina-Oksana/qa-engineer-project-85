# Codebattle — Знакомство с проектом

## О проекте

[**Codebattle**}(https://codebattle.hexlet.io/) — это opensource-проект [Хекслета](https://hexlet.ru) с многолетней историей, который разрабатывается силами сообщества. Это игра для программистов, где два участника соревнуются в решении одной и той же задачи на разных языках программирования. Побеждает тот, кто справится быстрее.

## Основные возможности

- **PvP-режим:** Соревнование с другим игроком в реальном времени
- **Игра с ботом:** Тренировка без необходимости искать соперника
- **Игра с другом:** Создание приватной игры со ссылкой-приглашением
- **Выбор сложности:** Возможность выбрать конкретную задачу или играть случайную
- **Мультиязычность:** Условия задач доступны на русском и английском
- **Режим зрителя:** Наблюдение за играми других участников
- **Встроенный чат:** Общение с другими игроками во время игры
- **Replay-режим:** Просмотр завершенных игр в формате видеозаписи с редактором кода
- **Рейтинговая система:** Статистика и очки за неделю, месяц и всё время
